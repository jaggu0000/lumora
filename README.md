# Lumora

Lumora is a modern JavaScript web application (frontend + backend). This repository is a fork of the original project and contains the source for both the client and server parts of the app, with a production deployment on Vercel.

Demo
- Live site: https://lumora-theta-eight.vercel.app

Project structure
- client/ — frontend application
- server/ — backend API
- README.md — this file

Key points
- Language: JavaScript
- Structure: monorepo-style with separate frontend and backend folders
- Deployment: configured to deploy on Vercel

Features
- Interactive frontend built with a modern web framework
- Backend API for application data and services
- Scripts for local development and production build

Getting started (local development)

Prerequisites
- Node.js 16+ (or the version required by the project)
- npm or yarn
